\title{\bf Grafts Add Up:\\ Scoring Every Layer Swap\\ in One Forward--Backward Pass}
\author{Anonymous authors}
\date{}

\begin{document}
\maketitle

\begin{abstract}
Layer swapping combines two models fine-tuned from the same base by replacing
some layers of one model with layers of the other. Choosing which layers to swap
usually requires building and testing many merged models. We study whether the
effect of each donor layer can instead be scored on the host model's own
trajectory. The scores add across swapped layers; the error is second order
when both experts stay near their shared base. \textsc{Suture} uses these scores to rank layer windows from
one forward and backward pass per probe, then uses a fixed number of built
models to calibrate a language constraint and check its choice. Controlled
stacks support the approximation for small expert changes and show where its
ranking weakens. On public multilingual models, selected windows improve a
teacher-forced answer measure over the host but do not surpass published
windows. Their effect on the language of free generation remains unmeasured.
The method offers a way to narrow layer-swap search while keeping the final
choice subject to direct validation.
\end{abstract}

% ============================================================================
\section{Introduction}
% ============================================================================

Layer swapping combines experts trained from a shared base by replacing a band
of one model's layers with layers from another. It can transfer mathematical
reasoning to a language without task data \citep{bandarkar2025layerswap}, and
has also been studied for long reasoning and multilingual safety
\citep{lasbordes2026rethinking,shin2026safetyswap}. The choice of layers matters:
a swap may import a skill while changing the host's output language.

Existing selection methods use a sweep or search over built candidates
\citep{lasbordes2026rethinking,akiba2025evolutionary}, train a predictor on
merges \citep{akizuki2025surrogate}, or rank layers using parameter statistics
\citep{bandarkar2025layerswap,shin2026safetyswap}. The last approach avoids
candidate builds but does not use a task or language readout. We ask whether a
single pass through the host can provide readout-specific scores for every
possible window before any merged model is built.

Our starting point is to evaluate each donor layer on the states produced by
the host. This gives one output difference per layer, independent of the other
swaps. Multiplying that difference by the host readout gradient gives a score
for the layer. For smooth layers and small grafts, the scores add across a set
of swaps with a bounded remainder (Section~\ref{sec:theory}). Thus any window
can be scored by adding its layer scores. The first-order attribution itself
is related to weight patching \citep{sun2026weightpatching}; here we use the
additive scores to choose among windows under a language constraint.

\textsc{Suture} scores task and language readouts, calibrates the language
constraint on built windows, and checks the selected window directly
(Section~\ref{sec:method}). We test the approximation and selection procedure
in controlled stacks where every window can be measured, then evaluate public
multilingual specialists with a narrower teacher-forced measure
(Sections~\ref{sec:verify} and~\ref{sec:protocol}). The readout does not
establish the language of free generation.

\paragraph{Contributions.}
We give a first-order decomposition for arbitrary graft sets, a window-selection
procedure with a fixed build budget, and controlled tests that show both useful
ranking and its limits. The public-model study checks how much of this account
transfers to multilingual specialists while reporting where the current
evidence ends.

\section{Choosing a band is a constrained program}
\label{sec:setup}
% ============================================================================

Choosing a layer window requires balancing the capability imported from the
donor against the host behavior we want to keep. Let a decoder apply
$L$ residual units to a state $x_\ell \in \Rb^{T\times d}$,
\begin{equation}
x_{\ell+1} \;=\; x_\ell + B_\ell(x_\ell;\theta_\ell), \qquad \ell = 0,\dots,L-1,
\end{equation}
with embedding and unembedding fixed. A host expert $\theta^{\host}$ and a donor
expert $\theta^{\donor}$ are fine-tuned independently from a shared base
$\theta^{\base}$. As in \citet{bandarkar2025layerswap}, the host is the expert
whose surface behavior we keep and the donor is the expert whose internal
capability we import; in the cross-lingual case the host speaks the target
language and the donor reasons.

For $S\subseteq\{0,\dots,L-1\}$, the \emph{graft} $\theta^{S}$ takes donor
parameters at the layers in $S$ and host parameters elsewhere. We call any such
$S$ a \emph{graft set}, a contiguous one a \emph{window}, and the window a
practitioner finally swaps a \emph{band}; layer swapping searches over windows.
The theory holds for any partition into sequential units, but units are whole
layers here.

Two scalar readouts are computed from the final state at the last prompt
position. The \emph{task} readout $\varphi_\util$ measures the imported
capability, the \emph{language} readout $\varphi_\risk$ how strongly the host
keeps its output language. Both are differentiable next-token log-probability
functionals that need no human annotation (Section~\ref{sec:method}). Each has
its own probe set and may depend on the probe through its answer tokens; we write
$\varphi$ for $\varphi_p$. With
$\Delta\varphi(S) = \Ex_p[\varphi(x_L^{S}(p)) - \varphi(x_L^{\host}(p))]$, where the expectation runs over the readout's probes, the
selection problem is
\begin{equation}
\label{eq:program}
\max_{S\in\mathcal{S}} \;\Delta\varphi_\util(S)
\qquad \text{subject to} \qquad
\Delta\varphi_\risk(S) \;\ge\; -\tau ,
\end{equation}
with $\mathcal{S}$ the windows or the full power set. A sweep solves
\eqref{eq:program} by building a merged model for each candidate. When the
objective is a target-language benchmark it also needs labels in a language
that by assumption has none; the surrogate readouts below remove that second
cost but not the first. The constraint is usually checked after the fact, by
measuring or reading the language of generated samples. Methods that tune
coefficients through the merged model \citep{yang2024adamerging, symerge2026}
also require model evaluations during search. The next section gives a way to
score windows before building them.
We use the first-response-token scalar because it is the differentiable
readout needed by Theorem~\ref{thm:superposition}; this is an analytical
compromise, not a claim that first-token confidence captures compounding
autoregressive errors or mid-generation language collapse.

% ============================================================================
\section{Why grafts add up}
\label{sec:theory}
% ============================================================================

The structure of \eqref{eq:program} is cheaper than its values. Two per-layer
quantities, both taken from the host's own forward and backward pass on a probe
$p$, carry all of it. The \emph{injection} $v_\ell$ is the change in what layer
$\ell$ adds to the residual stream when the donor's layer replaces the host's,
evaluated at the host's input to that layer. The \emph{adjoint}
$s^{\varphi}_\ell$ is the gradient of the readout with respect to the residual
stream just after layer $\ell$, with the later layers held at the host's:
\begin{equation}
\label{def:injection}
v_\ell := B_\ell\!\left(x^{\host}_\ell;\theta^{\donor}_\ell\right)-B_\ell\!\left(x^{\host}_\ell;\theta^{\host}_\ell\right),
\qquad
s^{\varphi}_\ell := \frac{\partial\varphi\!\left(x^{\host}_L\right)}{\partial x_{\ell+1}},
\qquad
a^{\varphi}_\ell := \Ex_p\big\langle s^{\varphi}_\ell(p),\,v_\ell(p)\big\rangle .
\end{equation}
Both $v_\ell$ and $s^{\varphi}_\ell$ live in $\Rb^{T\times d}$, and the inner
product runs over all positions and dimensions, so $a^{\varphi}_\ell$ is in the
units of the readout. All $L$ injections come from evaluating each donor layer
beside the host during one forward pass, and all $L$ adjoints from one backward
pass. The score $a^{\varphi}_\ell$ is the first-order change in the readout when
layer $\ell$ alone is swapped; the result below says that these single-layer
scores also predict every multi-layer graft.

\begin{theorem}[Grafts add up]
\label{thm:superposition}
Suppose the layers and the readout are smooth near the host's trajectory
(Assumption~\ref{ass:smooth} in Appendix~\ref{app:proof-superposition}). Then
every graft set $S$ that is admissible, meaning small enough for its trajectory
to stay in that region, satisfies
\begin{equation}
\label{eq:superposition}
\Delta\varphi(S)=\sum_{\ell\in S}a^{\varphi}_\ell+r(S),
\qquad
|r(S)|\le C_1\,\lambda\,\varepsilon_S+C_2\,\varepsilon_S^{2},
\end{equation}
where $\varepsilon_S=\sup_p\sum_{\ell\in S}\|v_\ell(p)\|$ is the size of the
graft, $\lambda$ bounds the difference between the two experts' layer Jacobians
along the host's trajectory, and $C_1,C_2$ depend only on the depth, the
smoothness constants, and the readout.
\end{theorem}

\paragraph{Why it holds.}
Each injection is computed on the host's own trajectory, so it does not depend on
which other layers are grafted, and the host carries each to the readout linearly
to first order, so the effects add. The remainder collects what this misses: the
curvature of each layer and of the readout, and the difference between how the
two experts respond to the deviation earlier grafts already caused. The argument is a
standard perturbation expansion; what matters is the expansion point, which makes
every term independent of the rest of the graft. If both experts are fine-tuned
by a small amount $t$ from the same base, and the layers are smooth in their
parameters, then $\lambda$ and $\varepsilon_S$ are $O(t)$, so the scores are
$O(t)$ and the remainder $O(t^2)$, which Figure~\ref{fig:verify}(b) tests. The
constants grow exponentially with depth, so we never use them numerically.

The identity is what makes the program cheap. Every graft set is scored by a
subset sum of $L$ numbers per readout, so both the objective and the constraint
of \eqref{eq:program} are linear in the indicator of $S$, and one host pass per
probe scores all $2^L$ compositions.

Scores rank candidates; they prove nothing about the one we pick. Two
elementary facts close that gap, and Section~\ref{sec:method} puts them to work:
a score gap wider than the two remainders settles a comparison, and the largest
remainder among a few built competitors bounds that of an unbuilt one drawn
uniformly (Proposition~\ref{prop:regret}, proved in
Appendix~\ref{app:proof-superposition}).

\section{\textsc{Suture}: from scores to a certified choice}
\label{sec:method}
% ============================================================================

\textsc{Suture} turns Section~\ref{sec:theory} into four steps
(Algorithm~\ref{alg:suture}): score every layer, calibrate the language scores on
ten built windows, choose a band, and build it to certify the choice. Units are
whole decoder layers. The composed model
$\theta^{S}$ takes the donor's complete decoder layers at the indices in $S$,
including their normalization weights, and takes everything else from the host,
including the embedding, the final normalization, and the output head.

\paragraph{Readouts.}
Both readouts are next-token log-probability functionals at the first response
position of a probe prompt $p$, so each costs one forward and one backward pass
and needs no generation:
\begin{equation}
\label{eq:readouts}
\varphi_\util(p)=\log\!\sum_{y\in\mathcal{T}_{\mathrm{ans}}(p)}\!P(y\mid p),
\qquad
\varphi_\risk(p)=\log\!\sum_{y\in\mathcal{T}_{\mathrm{own}}}\!P(y\mid p)-\log\!\sum_{y\in\mathcal{T}_{\mathrm{en}}}\!P(y\mid p).
\end{equation}
A task probe is a question machine-translated from the \emph{training} split of
GSM8K \citep{cobbe2021gsm8k} followed by ``Answer:'', with
$\mathcal{T}_{\mathrm{ans}}(p)$ the tokens of its gold numeric answer, inherited
from the English source. A language probe is a target-language passage followed
by an instruction to respond in that language, with $\mathcal{T}_{\mathrm{own}}$
the tokens of the language's own name and $\mathcal{T}_{\mathrm{en}}$ those of
``English''. Both pass through the host's final normalization and output head, so
they are differentiable in $x_L$, as Theorem~\ref{thm:superposition} requires.
For a multi-token answer or language name, these are deliberately bags of
protocol-listed candidate tokens at the first response position, not sequence
likelihoods: the adjoint only sees the distribution at that position. This
choice keeps the scalar differentiable and makes clear what the proxy does not
measure.
How closely $\varphi_\risk$ agrees with the language of free generation has not
been measured (Section~\ref{sec:limitations});
Appendix~\ref{app:protocol} gives templates, token sets, and probe counts.

\paragraph{Scores.}
For each readout, $a^{\varphi}_\ell$ is the probe average of
$\langle s^{\varphi}_\ell,v_\ell\rangle$, as in \eqref{def:injection}, with the
inner product over all positions and hidden dimensions. The injection $v_\ell$ is
the output of donor layer $\ell$ minus that of host layer $\ell$, both applied to
the host's input to layer $\ell$ with the host's attention mask and position
embeddings; $s^{\varphi}_\ell$ is the gradient of $\varphi$ with respect to the
output of host layer $\ell$. Probes are scored one at a time, so no padding
enters the scores.

\paragraph{Calibrate, then choose.}
A band is a window $[i,j]$ of consecutive layers, and
$A_\varphi(S)=\sum_{\ell\in S}a^{\varphi}_\ell$. Scores rank windows well but can
misstate magnitudes once a readout saturates, and the constraint depends on
magnitudes (Section~\ref{sec:verify}). \textsc{Suture} therefore builds $m_c=10$
uniformly drawn windows, measures $\Delta\varphi_\risk$ on them, and fits the
slope $b$ of $\Delta\varphi_\risk$ on $A_\risk$ through the origin. It then
selects
\begin{equation}
\label{eq:select}
\widehat{S}=\arg\max_{S\in\mathcal{F}}A_\util(S),
\qquad
\mathcal{F}=\{\text{windows } S : b\,A_\risk(S)\ge-\tau\},
\end{equation}
the calibrated first-order version of \eqref{eq:program}. All $L(L+1)/2$ windows,
$666$ for a 36-layer model, have proxy scores computed exactly from prefix sums. We fix $\tau=0.05$ nats before any measurement;
we leave $A_\util$ uncalibrated because only its ordering enters this argmax;
using the same builds to calibrate it could instead reduce the task-remainder
variance in the certificate, but is not part of the default procedure.
In the seeded stack the choice is stable across
$\tau\in\{0.02,0.05,0.10,0.20,0.40\}$, selecting $[8,10]$ at every value but the
tightest, where it falls back to $[1,2]$, and satisfying the true constraint in
all five cases (Table~\ref{tab:verify-full}). The implementation returns the best
feasible non-empty window, then builds it and measures its true language change.
If that change violates $-\tau$, it falls back to the best truly feasible
calibration window, or to the host if none exists, and reports the violation
instead of silently returning an infeasible choice. The host should also be kept
if $\mathcal{F}$ is empty or that window's predicted gain is not positive. The
conformal certificate requires $|\mathcal{F}|\ge m+2$; when fewer feasible
competitors exist, the selected window is returned without a certificate. The
original 8B selections of Section~\ref{sec:protocol} used $b=1$; the isolated
follow-up then fitted $b$ and left those windows unchanged.

\paragraph{Build once and certify.}
Now $\theta^{\widehat{S}}$ is built and its language loss measured, together with
$m$ windows drawn uniformly without replacement from
$\mathcal{F}\setminus\{\widehat{S}\}$ when $|\mathcal{F}|\ge m+2$.
Measuring $\varphi_\util$ on each built
window, on the probes used for scoring, gives its remainder
$r(S)=\Delta\varphi_\util(S)-A_\util(S)$. With $q$ the largest $|r|$ among the
$m$ draws, a competitor $S$ is certified when
$A_\util(\widehat{S})-A_\util(S)>q+|r(\widehat{S})|$. By
Proposition~\ref{prop:regret} an unbuilt competitor drawn uniformly has
$|r(S)|\le q$ with probability at least $m/(m{+}1)$, and a built one has
$|r(S)|\le q$ outright; either way it cannot then beat $\widehat{S}$. We use
$m=10$, bounding that failure probability by $1/11$ and bringing the procedure to
$21$ built models. The statement is about $\varphi_\util$ on the scoring probes,
not about downstream accuracy, and it has been evaluated in controlled stacks but
not on language models.

Donor layers are streamed one at a time during scoring, so peak memory is one
host model plus one layer.

\hrule height 0.8pt
\vspace{3pt}
\captionof{algorithm}{\textsc{Suture}. Lines 2--7 score every layer from one host
forward--backward pass per probe; $s^{\varphi}_\ell$ and $v_\ell$ must come from
the same host pass and probe. Lines 8--9 calibrate the language scores on ten
built windows and choose; later lines build the choice, fall back if the measured
language change violates the constraint, and otherwise certify it.}
\label{alg:suture}
\vspace{2pt}
\hrule height 0.4pt
\vspace{3pt}
\footnotesize
\begin{algorithmic}[1]
\STATE {\bfseries Input:} host $\theta^{\host}$, donor $\theta^{\donor}$, probes
$\mathcal{P}_\util,\mathcal{P}_\risk$, tolerance $\tau$, sizes $m_c$ and $m$
\FOR{$\varphi \in \{\varphi_\util, \varphi_\risk\}$ and each $p \in \mathcal{P}_\varphi$}
  \STATE host forward pass on $p$, caching the input $x^{\host}_\ell$ and the output of every layer
  \STATE for each $\ell$, apply donor layer $\ell$ to $x^{\host}_\ell$ with the host's mask and positions; store $v_\ell$ \hfill\COMMENT{streamed}
  \STATE backward pass from $\varphi(p)$, reading off $s^{\varphi}_\ell$ at every layer output
  \STATE accumulate $a^{\varphi}_\ell \mathrel{+}= \langle s^{\varphi}_\ell, v_\ell\rangle / |\mathcal{P}_\varphi|$
\ENDFOR
\STATE build $m_c$ uniformly drawn windows; measure $\Delta\varphi_\util$ and $\Delta\varphi_\risk$; fit $b$ from the latter against $A_\risk$ and retain them as $\mathcal{C}$
\STATE score every window by prefix sums; $\widehat{S}\leftarrow$ \eqref{eq:select}
\STATE build $\widehat{S}$; measure its $\Delta\varphi_\util$ and $\Delta\varphi_\risk$
\IF{$\Delta\varphi_\risk(\widehat{S})<-\tau$}
  \STATE $\mathcal{C}_{\rm feas}\leftarrow\{S\in\mathcal{C}:\Delta\varphi_\risk(S)\ge-\tau\}\cup\{\emptyset\}$; set both host changes to $0$
  \STATE {\bfseries return} the best $\widehat{S}_{\rm fb}\in\mathcal{C}_{\rm feas}$ by measured $\Delta\varphi_\util$, its measured language change, and the violation of $\widehat{S}$
\ELSE
  \IF{$|\mathcal{F}|\ge m+2$}
    \STATE build $m$ windows from $\mathcal{F}\setminus\{\widehat{S}\}$; measure each $r=\Delta\varphi_\util-A_\util$
    \STATE $q \leftarrow$ the largest $|r|$ among the $m$ draws
    \STATE {\bfseries return} $\widehat{S}$, its measured $\Delta\varphi_\risk$, and every $S\in\mathcal{F}\setminus\{\widehat{S}\}$ with $A_\util(\widehat{S})-A_\util(S)>q+|r(\widehat{S})|$
  \ELSE
    \STATE {\bfseries return} $\widehat{S}$ and its measured $\Delta\varphi_\risk$ without a certificate
  \ENDIF
\ENDIF
\end{algorithmic}

\end{minipage}

\section{Controlled stacks: the identity, the mechanism, and its limit}
\label{sec:verify}
% ============================================================================

The claims of Sections~\ref{sec:theory} and~\ref{sec:method} can be checked where
exhaustive search is affordable: residual stacks with $L=12$ blocks, $d=24$ and
$T=5$ positions, two experts made from a shared base, and a next-token
log-probability readout of the same form as the language-model readouts. Each
block layer-normalizes its input, mixes positions causally, and applies a
position-wise \textsc{Gelu} MLP, so the trajectory carries the normalization and
nonlinearity that the theorem's smoothness assumption has to survive; the mixing
matrix is fixed rather than input-dependent, so these stacks do not test
attention. Five questions follow the
story. Does the identity hold? Does the score need both factors, and does it beat
the closest baselines at an equal number of built models? Does selection respect
a constraint? Is the certificate sound? Where does ranking stop? Two settings
answer them: experts made by random perturbation, and experts obtained by
gradient fine-tuning, scored and judged on disjoint inputs. The seeded-stack
checks are recomputed by the retained NumPy harnesses. The multi-stack plots
and tables use frozen aggregates.
This is not language-model evidence, since here the ground truth \emph{is} the
readout the score is built from.

\paragraph{The identity holds.}
Predicted and measured change agree over random graft sets of every size, at
Pearson $0.980$ in the seeded stack; Figure~\ref{fig:verify}(a) shows the
per-stack Pearson values, with a multi-stack median of $0.95$ over $48$ stacks.

$2.055$ (Figure~\ref{fig:verify}(b)), while the aggregate over the three
smallest scales in Table~\ref{tab:verify-full} gives $2.045$.

\paragraph{The score needs both factors.} Table~\ref{tab:verify} removes one factor at a
time from $\langle s_\ell, v_\ell\rangle$. Windows have fixed width, so a score
summing non-negative magnitudes cannot win by taking the largest one, and
per-layer expert gaps span $4\times$, so parameter statistics have variation to
rank. Read the regret column: unlike a rank correlation it does not depend on a
sign an unsigned score cannot know. The full
score selects at regret $0.006$. Dropping the adjoint gives $0.21$, dropping the
injection $0.12$, movement from the base $0.19$, and random scores $0.20$; every
alternative is worse on the same stacks (Holm-adjusted $p\le0.016$), and $48$
stacks leave the order unchanged ($0.011$ against $0.16$--$0.24$, all
$p<10^{-5}$). Movement from the base, the statistic behind the original band
\citep{bandarkar2025layerswap}, is not distinguishable from random scores here
($0.192$ against $0.201$, paired $p=0.91$), because nothing in this construction
ties parameter magnitude to the readout; width-3 windows give the same picture
(Appendix~\ref{app:verify}). The specificity rows are a control:
the score built for readout $B$ ranks $B$ at $0.92$ while the score for $A$ does
not ($-0.04$), matching the near-zero correlation between the two readouts'
effects ($-0.06$).

\paragraph{Against the closest baselines.}
First-order weight attribution, the closest per-layer score, is indistinguishable
from \textsc{Suture} here. It ranks worse only as fine-tuning grows: Spearman
$0.49$ against $0.59$ at scale $0.4$, with no significant regret difference
(Table~\ref{tab:robustness}). A Sens-Merging-style sensitivity
\citep{liu2025sensmerging} is no more distinguishable from random scores
($0.241$ against $0.264$, paired $p=0.42$) than movement was. Search pays in
builds: the best of $11$ random windows still has regret $0.062$, against
$0.013$ for scores that build nothing.

\paragraph{Trained experts and held-out inputs.}
Random perturbations are a weak testbed, and scoring and judging on one input is
a weak protocol. We repeat the comparison with gradient-trained experts, scored
on eight probe inputs and judged on eight disjoint held-out ones, every
build-based baseline choosing among its built windows by the same probe readout
(Table~\ref{tab:trained}). Held-out ranking stays high
over all $78$ windows ($0.98\pm0.02$ over $48$ stacks). Table~\ref{tab:trained}
reports the seven width-$6$ diagnostic, where \textsc{Suture} reaches
$0.64\pm0.48$ and still beats random scores and both one-factor ablations, but
gradient training
couples movement from the base
to the injections (Pearson $0.87$), so movement selects almost as well and
neither it nor weight attribution separates from the full score. A
readout-agnostic statistic can stand in here because the construction aligns the
two behaviors, the truths anticorrelating at $-0.96$; under random perturbation
they are unrelated ($-0.06$) and movement is no better than random
(Appendix~\ref{app:verify}). Which regime real pairs fall into is untested. What the scores buy is builds
(Table~\ref{tab:trained}; Figure~\ref{fig:verify}(d)): with none, \textsc{Suture} reaches regret $0.013$
against $0.002$ for a full $78$-window sweep, a difference that is not
significant (Holm-adjusted $p=0.95$), while random search and hill climbing with
$11$ builds stay far behind. Figure~\ref{fig:verify}(f) summarizes the
corresponding width-$6$ regret contrast between perturbed and trained experts.

\paragraph{Selection under a constraint needs calibration.}
The constraint is where the two settings part. Under random perturbation, with
readout $B$ as the constraint and thresholds on the true scale, the selected
window is truly feasible in $0.94$, $0.79$ and $0.83$ of draws. With trained
experts the raw language scores understate the loss so badly that the selection
is feasible in $4$, $3$ and $0$ of $48$ stacks. Fitting one slope on ten built windows repairs it, to $0.93$,
$0.85$ and $0.79$ of draws,
which is why Section~\ref{sec:method} calibrates first. Ranking was never the problem: the
language scores rank the true loss at Spearman $0.98$.

\paragraph{The certificate behaves as predicted.}
In the seeded stack the selection is the true optimum of all $78$ windows, and
the margin condition certifies $75$ competitors with every remainder known, $71$
from $m=10$ sampled ones, neither falsely. Over
$12$ stacks it certifies $61.3\pm11.1$ of $77$ from $11$ built models with none
false; over $48$ stacks it makes $0.09$ false certifications per draw, $0.15\%$
of all certifications, consistent with a guarantee that holds per competitor
rather than simultaneously (Figure~\ref{fig:verify}(e)). Growing $m$ from $5$ to $40$ lowers that rate to
$0.02$ at a small cost in certified competitors (Table~\ref{tab:robustness}).

\paragraph{Where ranking stops.}
Figure~\ref{fig:verify}(c) shows the multi-stack diagnostic: mean ranking and
certification deteriorate as the experts move away from the base, reaching
Spearman $0.59$ and a certified share of $0.31$ at scale $0.4$. Depth does the
same, to $0.89$ at depth $24$, and false certifications become frequent in both
regimes (Table~\ref{tab:robustness}).
Magnitude error stays worse than order:
$9\%$ and $18\%$ at scales $0.05$ and $0.1$, where the order is exact
(Table~\ref{tab:verify-full}). In the worst of $48$ stacks
(superposition $0.50$) the selection was still optimal and the certificate shrank
to about $30$ of $77$ competitors, none false. \textsc{Suture} ranks; it does not predict how much a
composition will help, and it should not be trusted beyond the scale at which
ranking breaks.

\section{Language models: what holds at scale, and what does not yet}
\label{sec:protocol}
% ============================================================================

Controlled stacks cannot show that the ranking survives on real experts or
under free generation. We report three real-model studies, each under a protocol
fixed before its measurement (Appendix~\ref{app:protocol}).

\paragraph{Public 8B specialists.}
We took the Qwen3-8B native specialists of \citet{lasbordes2026rethinking} for
French and Chinese as hosts and their English specialist as donor. Selection
scored all $666$ windows of the 36-layer model, with no grafted model built,
and chose layers $[13,15]$ for French and $[20,31]$ for Chinese (zero-based). On
$250$ MGSM-Rev2 test records per language, disjoint from the probes, the selected
windows raised mean teacher-forced answer log-probability over the host by
$+0.398$ nats per token in French (paired bootstrap $95\%$ interval
$[+0.358,+0.437]$) and by $+1.326$ in Chinese ($[+1.210,+1.446]$).
The host means were $-8.808$ and $-9.516$ nats per token, respectively. The
same records were used to measure the published windows (layers 13--22 and
13--20): selected minus published was $-0.355$ nats per token in French
(paired bootstrap $95\%$ interval $[-0.417,-0.293]$) and $-0.131$ in Chinese
($[-0.222,-0.039]$), so the selected intervals beat the host but lose to the
published references. All intervals use zero-based inclusive layer indices:
the published $[13,22]$ and $[13,20]$ intervals therefore match the selected
intervals' convention.
Three limits matter: the answer readout is close to but not the task readout, and
neither is free-generation accuracy; a decoding-cache mismatch prevented the
latter. An isolated A100 follow-up fit the language
scale on ten windows: $b=0.452$ (RMSE $0.747$) for French and $b=0.012$
(RMSE $0.916$) for Chinese, leaving the selected windows $[13,15]$ and
$[20,31]$. Parameter movement selected $[0,35]$ in both languages, while
first-order weight attribution selected the same constrained windows; without
the constraint it selected French $[22,32]$, gaining $+1.243$ answer nats but
losing $-1.259$ language-readout units. The conformal certificate was not run.
Algorithm~\ref{alg:suture} specifies a measured calibration-window fallback if a
future choice violates the constraint.
The Chinese window extends past layer 20, where
\citet{lasbordes2026rethinking} saw traces revert to English. On $76$ held-out
language probes, selected-minus-host was $(+1.070,+0.268)$ and
selected-minus-published $(+0.130,-0.315)$ (French, Chinese). The proxy supports a host-relative gain but not
the Chinese comparison with the published window; generated-text language
identification remains unmeasured.

\paragraph{A weak 1.5B pair: free-generation ranking is inconclusive.}
On Qwen2.5-Coder-1.5B-Instruct, the only 1--2B decoder in our offline mirror, matched
LoRA experts gave a donor that added one correct item of $32$ in Spanish and
Chinese and none in Swahili. Over all $406$ Spanish windows the scores ranked
teacher-forced log-probability on eight MGSM development items
\citep{shi2022mgsm} at Spearman $0.877$, but free-generation exact match at
$-0.018$. With $40$ Bernoulli trials per window near a rate of $0.1$, that value
is indistinguishable from chance (Appendix~\ref{app:protocol}), and a later
greedy ranking on $64$ held-out items reached only $0.129$, below the
pre-specified $0.5$. This donor was
trained on the GSM8K questions the probes are drawn from, so its probe scores are
in-sample, while the ranking targets come from the disjoint MGSM split. On $24$
fixed windows an adjoint-only score ranked teacher-forced outcomes better than
the full score ($0.803$ against $0.583$), the reverse of the controlled ablation.
A third attempt, on Qwen3-1.7B, stopped before ranking at the host-language and
implementation checks (Appendix~\ref{app:protocol}).

\section{Related work}
\label{sec:related}
% ============================================================================

Three literatures meet here: layer swapping, model-merging search, and
first-order attribution.

\paragraph{Layer swapping and multilingual composition.}
\citet{bandarkar2025layerswap} introduced layer swapping and selected its band
from expert parameter movement; later work found little overlap between
math- and language-important parameters \citep{bandarkar2025unreasonable},
extended the recipe to long reasoning and safety
\citep{lasbordes2026rethinking, shin2026safetyswap}, and made merging
input-steerable \citep{li2026stmerge}. This lineage includes task arithmetic and
composable sparse fine-tuning \citep{ilharco2023task, chronopoulou2024langtask,
ansell2022sft}, but these methods do not predict a band's behavioral effect
before construction; Theorem~\ref{thm:superposition} does so to first order.

\paragraph{How compositions are chosen.}
Evolutionary, Bayesian, and surrogate methods still evaluate individual merges
\citep{akiba2025evolutionary, merge3-2025, chen2025sipbmm, akizuki2025surrogate};
expert-intrinsic rules read weights rather than behavior
\citep{yadav2023ties, yu2024dare, jin2023regmean, liu2025sensmerging}; and
behavior-referenced or unlabeled proxies score one configuration at a time
\citep{yang2024adamerging, symerge2026, fu2026merit, tap2026}. StatsMerging
\citep{merugu2025statsmerging} and CAT Merging
\citep{sun2025cat} likewise operate in weight space, while MergeBench
\citep{he2025mergebench} benchmarks merged LLMs; none scores combinatorial layer
grafts under a language constraint.

\paragraph{Attribution and output language.}
Attribution patching and Weight Patching linearize activation or parameter
changes \citep{nanda2023attribution, syed2024attribution, sun2026weightpatching};
we do not claim that family as new (Table~\ref{tab:verify}). Our distinction is
exact host-path differencing for two independently tuned experts, a constrained
program over all $2^L$ sets, and a per-competitor remainder certificate.
Interpretability studies place language-agnostic computation mid-stack and
language commitment late \citep{wendler2024llamas, tang2024langneurons,
schut2025english}; work on confusion and late-layer failures
\citep{marchisio2024confusion, nie2025confusion} motivates retaining a language
readout.

\section{Implications and limitations}
\label{sec:limitations}
% ============================================================================

\paragraph{What a practitioner gets.}
A fixed budget of twenty-one builds calibrates and certifies one choice rather
than searching; a published band costs one build but is tied to its model and
language, and can send Chinese traces back to English
\citep{lasbordes2026rethinking}. The same scores rank arbitrary subsets at no
extra cost, but that extension is untested on language models.

\paragraph{Why swaps compose, and where they should stop.}
When the language readout tracks output language, the theorem predicts a stopping
boundary. Our held-out proxy supports only a host-relative teacher-forced gain,
not the Chinese selected-versus-published comparison; Appendix~\ref{app:negative}
shows why the free-generation claim may fail.

\paragraph{Limitations.}
At 8B the evidence covers two languages, one donor, and a teacher-forced
functional; selected intervals lose to published references, and generated-text
language identification is unmeasured. The certificate remains controlled-stack
only; an isolated follow-up ran 8B calibration and cheaper baselines. The 1.5B
study is inconclusive; local studies use one seed and machine-translated probes.
Fixed-attention stacks achieve only $0.64\pm0.48$ on the width-$6$ diagnostic; a
from-scratch transformer (Appendix~\ref{app:negative}) also failed to reproduce
transfer.

\section{Theory: assumption and proofs}
\label{app:proof-superposition}
% ============================================================================

This appendix states the assumption behind Theorem~\ref{thm:superposition},
proves the theorem through an identity on the residual stream, and proves
Proposition~\ref{prop:regret}. Norms are Frobenius norms on $\Rb^{T\times d}$
and the induced operator norms on linear maps of that space, and
$\langle\cdot,\cdot\rangle$ is the matching inner product. Each layer map
$B_\ell(\cdot\,;\theta)$ includes the probe's fixed attention mask and position
embeddings. We fix one probe until the last step of the proof of
Theorem~\ref{thm:superposition}, write $\Delta_\ell=x^{S}_\ell-x^{\host}_\ell$,
with $\Delta_0=0$ because the embedding is the host's, and write
$a(\ell)=\donor$ if $\ell\in S$ and $a(\ell)=\host$ otherwise.

\begin{assumption}[Smoothness near the host trajectory]
\label{ass:smooth}
There are constants $\rho,\Lambda,\kappa,\lambda,L_\varphi\ge0$ such that, for
every probe and every layer $\ell$, on the ball $\mathcal{B}_\ell$ of radius
$\rho$ around the host state $x^{\host}_\ell$: the map $x\mapsto B_\ell(x;\theta)$
is $\Lambda$-Lipschitz with a $\kappa$-Lipschitz Jacobian for $\theta$ equal to
the host's or the donor's layer parameters; and
$\|J^{\donor}_\ell-J^{\host}_\ell\|\le\lambda$, where $J^{\bullet}_\ell$ is the
Jacobian of layer $\ell$ at $x^{\host}_\ell$ under parameters $\bullet$. The
readout has an $L_\varphi$-Lipschitz gradient on the ball of radius $\rho$ around
$x^{\host}_L$. A graft set $S$ is \emph{admissible} if
$\gamma\,\varepsilon_S\le\rho$, where $\gamma=(1+\Lambda)^{L}$.
\end{assumption}

Because $\Lambda$ may depend on $\rho$, the two are chosen together. Nothing
here constrains smoothness in the parameters; only the scaling remark below uses
it.

\begin{lemma}[Superposition in the residual stream]
\label{lem:state}
Let $P_{\ell+1:L}=\prod_{k=L-1}^{\ell+1}\left(I+J^{\host}_k\right)$, the
Jacobian of the host map from the residual stream after layer $\ell$ to $x_L$
(the empty product is $I$), and let $\Gamma=\max_\ell\|P_{\ell+1:L}\|$. Under
Assumption~\ref{ass:smooth}, every admissible $S$ satisfies
\[
\Delta_L=\sum_{\ell\in S}P_{\ell+1:L}\,v_\ell+R(S),
\qquad
\|R(S)\|\le\Gamma\,\gamma\,\varepsilon_S\Big(|S|\,\lambda+\tfrac{\kappa}{2}\,L\,\gamma\,\varepsilon_S\Big),
\]
and $\Gamma\le\gamma$.
\end{lemma}

\paragraph{Proof of Lemma~\ref{lem:state}.}
By definition of the two trajectories,
\begin{align}
\Delta_{\ell+1}
&= \Delta_\ell
+ \underbrace{\left[B_\ell\!\left(x^{\host}_\ell;\theta^{a(\ell)}_\ell\right) - B_\ell\!\left(x^{\host}_\ell;\theta^{\host}_\ell\right)\right]}_{=\,\mathbf{1}[\ell\in S]\, v_\ell}
+ \underbrace{\left[B_\ell\!\left(x^{\host}_\ell+\Delta_\ell;\theta^{a(\ell)}_\ell\right) - B_\ell\!\left(x^{\host}_\ell;\theta^{a(\ell)}_\ell\right)\right]}_{\text{propagation}},
\end{align}
which is exact, since it only adds and subtracts
$B_\ell(x^{\host}_\ell;\theta^{a(\ell)}_\ell)$; it is verified numerically to
relative error $1.9\times10^{-15}$ (Table~\ref{tab:verify-full}), and
the retained \artifact{verify/verify\_theory.py} harness checks the recursion
and the second-order decay of the readout remainder numerically; this is a
numerical check, not a proof of the bound. If
$\|\Delta_\ell\|\le\rho$ the segment from $x^{\host}_\ell$ to
$x^{\host}_\ell+\Delta_\ell$ lies in the convex ball $\mathcal{B}_\ell$, so the
propagation term has norm at most $\Lambda\|\Delta_\ell\|$ and
$\|\Delta_{\ell+1}\|\le(1+\Lambda)\|\Delta_\ell\|+\mathbf{1}[\ell\in S]\|v_\ell\|$.
With $\Delta_0=0$, induction gives
\begin{equation}
\label{eq:apriori}
\|\Delta_\ell\| \;\le\; \sum_{k\in S,\, k<\ell} (1+\Lambda)^{\ell-1-k}\|v_k\| \;\le\; \gamma\,\varepsilon_S \;\le\; \rho
\qquad (\ell=0,\dots,L),
\end{equation}
the last step being admissibility, which is what keeps the hypothesis
$\|\Delta_\ell\|\le\rho$ true at every step.

Because the Jacobian of $B_\ell(\cdot\,;\theta^{a(\ell)}_\ell)$ is
$\kappa$-Lipschitz on $\mathcal{B}_\ell$, the propagation term equals
$J^{a(\ell)}_\ell\Delta_\ell+e_\ell$ with
$\|e_\ell\|=\big\|\int_0^1(J^{a(\ell)}_\ell(x^{\host}_\ell+u\Delta_\ell)-J^{a(\ell)}_\ell)\Delta_\ell\,du\big\|\le\tfrac{\kappa}{2}\|\Delta_\ell\|^2$.
Writing $J^{a(\ell)}_\ell=J^{\host}_\ell+\mathbf{1}[\ell\in S](J^{\donor}_\ell-J^{\host}_\ell)$,
\begin{equation}
\Delta_{\ell+1} = \left(I + J^{\host}_\ell\right)\Delta_\ell + \mathbf{1}[\ell\in S]\, v_\ell + q_\ell,
\qquad
\|q_\ell\| \le \mathbf{1}[\ell\in S]\,\lambda\|\Delta_\ell\| + \tfrac{\kappa}{2}\|\Delta_\ell\|^2 .
\end{equation}
Unrolling this linear recursion from $\Delta_0=0$ gives
$\Delta_L = \sum_{\ell\in S} P_{\ell+1:L} v_\ell + \sum_{\ell} P_{\ell+1:L} q_\ell$,
so $R(S)=\sum_\ell P_{\ell+1:L}q_\ell$. With \eqref{eq:apriori},
$\sum_\ell\|q_\ell\|\le|S|\lambda\gamma\varepsilon_S+L\tfrac{\kappa}{2}\gamma^2\varepsilon_S^2$,
and $\|P_{\ell+1:L}\|\le\Gamma$ gives the bound. Finally a $\Lambda$-Lipschitz
map has Jacobian norm at most $\Lambda$, so $\|I+J^{\host}_k\|\le1+\Lambda$ and
$\Gamma\le(1+\Lambda)^{L}=\gamma$. \hfill$\square$

\paragraph{Proof of Theorem~\ref{thm:superposition}.}
By \eqref{eq:apriori} at $\ell=L$, the segment from $x^{\host}_L$ to $x^{S}_L$
lies in the ball on which $\nabla\varphi$ is $L_\varphi$-Lipschitz, so
$\varphi(x^{S}_L)-\varphi(x^{\host}_L)=\langle\nabla\varphi(x^{\host}_L),\Delta_L\rangle+\eta$
with $|\eta|\le\tfrac{L_\varphi}{2}\|\Delta_L\|^2\le\tfrac{L_\varphi}{2}\gamma^2\varepsilon_S^2$.
By the chain rule, $P_{\ell+1:L}^{\top}\nabla\varphi(x^{\host}_L)$ is the gradient
of the readout with respect to the residual stream after layer $\ell$, that is,
$s^{\varphi}_\ell$, so
$\langle\nabla\varphi(x^{\host}_L),P_{\ell+1:L}v_\ell\rangle=\langle s^{\varphi}_\ell,v_\ell\rangle$.
Substituting Lemma~\ref{lem:state} and applying the Cauchy--Schwarz inequality to
$\langle\nabla\varphi(x^{\host}_L),R(S)\rangle$ gives, for this probe,
\[
\Big|\varphi(x^{S}_L)-\varphi(x^{\host}_L)-\sum_{\ell\in S}\langle s^{\varphi}_\ell,v_\ell\rangle\Big|
\le G\,\Gamma\,\gamma\,|S|\,\lambda\,\varepsilon_S+\Big(\tfrac{\kappa}{2}\,G\,\Gamma\,L+\tfrac{L_\varphi}{2}\Big)\gamma^2\varepsilon_S^2 ,
\]
where $G=\sup_p\|\nabla\varphi(x^{\host}_L(p))\|$. The right side does not
depend on the probe, so averaging over probes proves the theorem with
$C_1=G\,\Gamma\,\gamma\,L\le G\,L\,\gamma^2$ and
$C_2=\big(\tfrac{\kappa}{2}G\,\Gamma\,L+\tfrac{L_\varphi}{2}\big)\gamma^2\le\big(\tfrac{\kappa}{2}G\,L\,\gamma+\tfrac{L_\varphi}{2}\big)\gamma^2$,
using $|S|\le L$ and $\Gamma\le\gamma$. The two constants carry different units,
readout per state unit and readout per squared state unit, which is why the bound
keeps them apart. \hfill$\square$

\paragraph{Scaling with the fine-tuning size.}
Suppose, in addition, that $B_\ell$ and its Jacobian are Lipschitz in the
parameters near the base, that $\theta^{\host}=\theta^{\base}+t\,u^{\host}$ and
$\theta^{\donor}=\theta^{\base}+t\,u^{\donor}$, and that the constants of
Assumption~\ref{ass:smooth} can be taken uniform for small $t$. Then
$\|v_\ell\|=O(t)$ and $\lambda=O(t)$, so the scores are $O(t)$ and
$|r(S)|=O(t^2)$. This is the claim that Figure~\ref{fig:verify}(b) tests.

\begin{proposition}[Checking a choice]
\label{prop:regret}
Let $A(S)=\sum_{\ell\in S}a^{\varphi}_\ell$, and let $\widehat{S}$ maximize $A$
over a candidate set $\mathcal{F}$.
\textbf{(i)} For any $S$, if $A(\widehat{S})-A(S)>|r(S)|+|r(\widehat{S})|$, then
$\Delta\varphi(\widehat{S})>\Delta\varphi(S)$.
\textbf{(ii)} If $|\mathcal{F}|\ge m+2$ and $S_1,\dots,S_{m+1}$ are drawn
uniformly without replacement from $\mathcal{F}\setminus\{\widehat{S}\}$, then
$\Pr\big[\,|r(S_{m+1})|>\max_{i\le m}|r(S_i)|\,\big]\le 1/(m+1)$. Part (ii) is
the rank argument behind conformal prediction \citep{vovk2005,
angelopoulos2023gentle}.
\end{proposition}

\paragraph{Proof of Proposition~\ref{prop:regret}.}
(i) $\Delta\varphi(\widehat S)-\Delta\varphi(S)=A(\widehat S)-A(S)+r(\widehat S)-r(S)
>|r(S)|+|r(\widehat S)|+r(\widehat S)-r(S)\ge0$.
(ii) Once the probes are fixed, every $r(S)$ is a fixed number, so the only
randomness is the draw, and $|\mathcal{F}|\ge m+2$ guarantees $m+1$ distinct
competitors. Drawing without replacement makes
$|r(S_1)|,\dots,|r(S_{m+1})|$ exchangeable, so the last of them is the strict
maximum with probability at most $1/(m+1)$, with equality when ties have
probability zero. For the certificate of Section~\ref{sec:method}, a competitor
drawn uniformly from those not built forms such an exchangeable sequence with the
$m$ built ones. It can be falsely certified only if its $|r|$ exceeds $q$, since
otherwise part (i) applies, so a false certification has probability at most
$1/(m+1)$, and by linearity of expectation the expected number of false
certifications among the $|\mathcal{F}|-m-1$ unbuilt competitors is at most
$(|\mathcal{F}|-m-1)/(m+1)$. A built competitor has $|r|\le q$ by the definition
of $q$ and cannot be falsely certified. \hfill$\square$

\paragraph{What the results do not say.}
Part (ii) concerns a uniformly drawn competitor, not an adversarial one.
Theorem~\ref{thm:superposition} does not say the remainder is small at any
particular scale, and its constants are exponential in depth. It does not license
reading $\sum_{\ell\in S}a^{\varphi}_\ell$ as an estimate of how much a graft
helps: the order of the windows is exact at scales where the magnitude error is
already $9\%$ and $18\%$ (Table~\ref{tab:verify-full}). It assumes a shared architecture and base and differentiable layers,
excluding hard-routed mixture-of-experts blocks without smoothing.

\paragraph{Trained experts, held-out inputs, and calibration.}
Experts here are gradient-fine-tuned from a shared base, the host toward readout
$B$ and the donor toward readout $A$ on eight probe inputs, each total update

\paragraph{Readout specificity in the two settings.}
The trained-expert study ranks every zero-build score against both held-out
truths. All order the task readout and, with the sign reversed, the
language readout: \textsc{Suture}'s task score reaches $+0.98$ and $-0.97$,
movement $+0.96$ and $-0.96$. That follows from the construction, which leaves
the two truths anticorrelated at $-0.96\pm0.06$. The perturbed stacks separate
the readouts instead (truths correlate $-0.06$), and there a score built for one
does not rank the other (Table~\ref{tab:verify}). A constrained program needs
readout-specific scores whenever the imported capability and the kept behavior
are not two sides of one axis, which no experiment here settles for real experts.

\paragraph{A failure case.}
The weakest of the $48$ stacks (seed $1037$) has superposition Pearson $0.50$ and
all-window Spearman $0.56$; its predicted window values span $[-0.74,0.20]$ while
the true values span $[-0.24,0.22]$, and the largest remainder, $0.60$, belongs
to window $[0,7]$, which contains the two layers with the largest injections.
The selection is still the true optimum, because the best window's score margin
is large, and the deployable certificate becomes cautious rather than wrong: it
certifies about $30$ of $77$ competitors, none falsely. Large remainders thus
show up as fewer certified competitors, which is the behavior a practitioner can
observe without the sweep.

\section{Negative results and excluded claims}
\label{app:negative}

Three findings are recorded here because they bound what the paper may claim; no
claim rests on any of them.

The linearization has a regime. On the three 1.5B expert pairs the teacher-forced
diagnostic gives Spearman $0.72$, $0.89$ and $0.66$ with relative magnitude
errors $0.95$, $0.45$ and $1.85$, near or beyond the point where controlled-stack
ranking degrades (Figure~\ref{fig:verify}(c)), and the readouts are
teacher-forced while the failure that matters belongs to free generation.
% ============================================================================

\paragraph{An unsupported conjecture: the $\lambda$ factor is not predictive.}
Theorem~\ref{thm:superposition} bounds the remainder by a product containing the
donor--host Jacobian gap $\lambda$. A stronger, testable interpretation would
separate the analysis from a generic Taylor argument: with
the weight perturbation norm held fixed, expert pairs whose Jacobians agree more
closely should show a smaller linearization error. We tested this directly in the
controlled stack, sampling fourteen donors at a weight distance held constant to
within $0.00\%$ and varying only the direction. The correlation between $\lambda$
and the realized error was $-0.304$, the wrong sign, while weight distance, held
fixed by construction, correlated at $0.000$. The conjecture is not supported;
no claim in this paper rests on it. Theorem~\ref{thm:superposition} is unaffected,
since an upper bound containing $\lambda$ stays valid whether or not $\lambda$ is
tight; what fails is the stronger reading of $\lambda$ as a predictor. The check
is retained in the released harness as a negative result.

\paragraph{A testbed that did not reproduce the phenomenon.}
Section~\ref{sec:verify} verifies the mathematics on a stack whose experts are
constructed rather than trained, so it does not test transfer learned from
pretraining. We
therefore built a small transformer with attention, layer normalization and GELU
MLPs, wrote its backward pass by hand and gradient-checked it to a worst relative
error of $9\times10^{-9}$, pretrained it on a task whose input script and output
language are decoupled so that a script-independent value representation is
forced, and fine-tuned a skill expert and a language expert from that shared
base. The target cell, the skill in the language nobody was trained on, was left
genuinely unseen. Across two designs of the pretraining task no graft improved on
the host, and the best contiguous window was within noise of the host itself. One
hypothesis is that the phenomenon needs a base
whose multilingual representations are strong enough to survive expert
fine-tuning, which a small model trained from scratch on a synthetic task does not
have. The practical consequence is that the proposed language-model evaluation
should use a genuinely pretrained multilingual base; substituting a small
from-scratch model would not isolate the intended setting from the selection
method. The testbed is released so that the negative result is reproducible.

\section{Full experimental protocols}
\label{app:protocol}

Revisions and file hashes appear as their first eight hexadecimal characters;
the complete values are in the released run manifest.

\paragraph{Licenses and data.}
\artifact{Qwen/Qwen2.5-Coder-1.5B-Instruct} and \artifact{Qwen/Qwen3-1.7B} are
the official checkpoints, both Apache-2.0, and weights are not redistributed.
GSM8K is MIT, MGSM is CC-BY-SA-4.0 over that MIT source, and
\artifact{facebook/belebele} is CC-BY-SA-4.0 with its training set unused;
MetaMathQA was not used. Probes are translated by the pinned base of each study,
\artifact{2e1fd397}\ldots{} for Coder and \artifact{70d244cc}\ldots{} for Qwen3.
The Qwen3 Spanish split is \artifact{juletxara/mgsm:es:test}, divided by
\artifact{frozen\_mgsm\_indices} into $64$ hash-pinned development and $186$
holdout items; all file hashes are in the released manifest.

\paragraph{What was run.}
Three studies: public Qwen3-8B specialists (selection over all $666$ windows and
a held-out comparison of host, selected and published windows);
\artifact{Qwen/Qwen2.5-Coder-1.5B-Instruct} (matched LoRA experts and an
exhaustive $406$-window Spanish sweep); and \artifact{Qwen/Qwen3-1.7B}, which
stopped at the readiness checks. Safety-task and larger-scale sweeps were not
run. The 8B answer-measurement records and their manifests are released under
\artifact{results/b3/lighton\_qwen3\_8b/}; the isolated follow-up records are
not included, as stated in the reproducibility statement.
The isolated follow-up builder also translated the next $76$ disjoint language
records for each 8B host, and the isolated A100 follow-up scored the host,
selected, and published candidates on those records. These artifacts report a
teacher-forced language readout only; no generated-text language-ID rate was
obtained.

\paragraph{8B protocol.}
The public protocol file
\artifact{configs/b3\_lighton\_qwen3\_8b\_v1.json}
is loaded at runtime; it pins the English donor at revision
\artifact{3e1efbca}\ldots, the French host at
\artifact{a53d601e}\ldots, and the Chinese host at
\artifact{b100a627}\ldots. It uses
\artifact{lightonai/mgsm-rev2}@\artifact{1463c6dc}\ldots,
the test split, $250$ records per language, and all $666$ zero-based
contiguous intervals for selection.
The $500$ task probes are rows $0$--$499$ of
\artifact{openai/gsm8k}/\artifact{main}/\artifact{train}
at revision \artifact{740312add88f}\ldots; the $500$ language probes are the
first $500$ unique English records, after deterministic SHA-256 ordering, from
\artifact{CohereLabsCommunity/multilingual-reward-bench}/\artifact{translation}/
\artifact{test} at revision \artifact{04120fd1}\ldots. Both were translated
greedily with thinking disabled by \artifact{Qwen/Qwen3-1.7B} at revision
\artifact{70d244cc}\ldots. The selection \artifact{max\_length} is $128$;
the \artifact{data\_build\_summary.json} manifest checks that these probes are
pairwise disjoint from the $250$ MGSM-Rev2 test records.
Selection builds nothing; measurement compares host, selected interval and
published reference by mean teacher-forced answer log-probability per target
token. The isolated language-fidelity follow-up compares the same candidates
by target-language-minus-English first-token log-probability on $76$ held-out
records per language. It used one A100 PCIe 80GB, BF16, CUDA 12.4, Python
3.10.13, \artifact{torch==2.6.0+cu124} and
\artifact{transformers==5.14.1}; no generated-text language-ID rate was run.
The language-readout means (host, selected, published) were
$(2.644,3.714,3.584)$ in French and $(7.737,8.004,8.319)$ in Chinese.
Per-record language-fidelity measurements are released under
\artifact{results/b3/lighton\_qwen3\_8b/language\_fidelity\_records/}; the
translated probe inputs are released there; original run manifests remain author-only. The
path-free aggregate is
\artifact{results/b3/lighton\_qwen3\_8b/posthoc\_language\_fidelity.json}.

choices are in the pair-level
\artifact{results/b3/lighton\_qwen3\_8b/llm\_feedback\_followup/*/summary.json}
files; per-record follow-up measurements are not released.

\paragraph{Readouts and probes, per study.}
The readouts are those of \eqref{eq:readouts}, called \artifact{utility} and
\artifact{risk} in the code. At 8B, prompts use the Qwen3 chat template with
thinking disabled: a task probe is a translated GSM8K training question, a line
break and ``Answer:'', with $\mathcal{T}_{\mathrm{ans}}$ every token of the gold
number; a language probe is a translated passage, a line break and ``Respond
in'' with the language's own name, scored against ``English''. Passages are
English source sentences translated by a pinned model instructed to emit only
the translation (details in the protocol paragraph above). The Qwen2.5-Coder study uses
plain text with no chat template, $\mathcal{T}_{\mathrm{ans}}$ holding the
\emph{first} token of the gold number.
The Coder artifacts used for the reported window scores contain $200$ utility
and $200$ risk probes, as recorded in
\artifact{results/tier\_a/es/data\_build\_summary.json};
the later \artifact{src/suture/tier\_a\_config.py} default of $500$ per readout belongs to
the Qwen3-1.7B pipeline and is not the provenance of these Coder scores.
Its donor is fine-tuned on the GSM8K rows the task probes are drawn from, so
those probe scores are in-sample, while donor validation and readiness rows are
disjoint and the loader enforces it; the ranking targets come from the MGSM
split, and the 8B donor is a public checkpoint. Every probe is scored with batch
size $1$, and the probe sets are disjoint from every evaluation set.

\paragraph{Metrics that were measured.}
\emph{Task}: free-generation exact match on MGSM-dev. \emph{Drift}: fastText
identifier \citep{grave2018fasttext} mismatch on MGSM-dev, and on held-out $C$
($500$ prompts, five decode seeds, $n=2500$) an empirical $0.222$ with a post-hoc
Clopper--Pearson \citep{clopper1934} upper limit of $0.236$ at $\delta=0.05$,
conditional on an i.i.d.\ prompt--seed model that reusing prompts across seeds
does not establish. \emph{Target-language nonempty check}: passed at $1.000$ on
$32$ readiness-host prompts. Belebele and knowledge retention were not measured.
\emph{Cost}: zero merged models built during selection, $408$ during
measurement.

\paragraph{Statistics that were computed.} One expert-training seed and five
decoding seeds. Paired item bootstrap on selected-versus-best regret for the
eight MGSM-dev items. Holm correction across languages was specified for a
three-language ranking panel and is unused because only Spanish ranking ran.

\paragraph{Compute that was spent.}
The Spanish sweep covers $406$ windows over $28$ layers and built no model during
selection; its first $50$ windows ran before a resume and were not timed, the
remaining $356$ took $41{,}449$\,s. Local runs used one RTX 3060 Ti with CUDA and
bfloat16 under Python 3.11.9, \artifact{torch==2.6.0+cu124},
\artifact{transformers==5.14.1}, \artifact{peft==0.20.0},
\artifact{datasets==5.0.1}, \artifact{fasttext-wheel==0.9.2} and
\artifact{numpy==2.4.2}. Total GPU-hours were not logged.

\paragraph{8B compute.}
The two canonical pairs ran sequentially on one rented A100 PCIe 80GB with both
BF16 checkpoints resident: preflight checks, all $666$ intervals scored with no
grafted model built, then three candidates measured on $250$ held-out records.
The isolated follow-up reused those frozen score and measurement trees, fit the
language scale on ten windows per language, scored $500$ utility and $500$ risk
probes for each calibration and attribution pass, and measured only new
candidate windows. Wall time was not recorded.
